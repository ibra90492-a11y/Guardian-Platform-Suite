# Security And Ethics

## الأمان

- لا يتم تخزين كلمات المرور أو الأسرار داخل المنصة.
- الأوامر الخطيرة محظورة قبل التنفيذ.
- كل عملية تنفيذ تحتاج موافقة مسبقة.
- الفحص في نسخة MVP محدود للأهداف المحلية أو المختبرية المصرح بها.
- عند تعطل Nmap يستخدم النظام فحص منافذ بديل آمن ومحدود.

## الترخيص والاستخدام

هذه المنصة مخصصة للاستخدام الأخلاقي والدفاعي فقط. يجب الحصول على موافقة خطية من الجهة المالكة للنظام قبل أي اختبار أو فحص.

## حدود المسؤولية

الجهة المالكة للنظام مسؤولة عن تحديد نطاق الاختبار وتنفيذ التوصيات. لا ينبغي استخدام النتائج كبديل عن تقييم أمني رسمي كامل إلا بعد مراجعة بشرية مختصة.
