# WiFi Guardian Toolkit 🛡️

## نظام شامل لحماية وحماية شبكات WiFi

### 📋 نظرة عامة

WiFi Guardian Toolkit هي مجموعة شاملة من أدوات PowerShell المتقدمة لفحص وتحليل وتأمين شبكات WiFi. توفر الأداة:

- ✅ فحص أمني متقدم وشامل
- ✅ اكتشاف تلقائي لجميع الأجهزة المتصلة
- ✅ تقارير منسقة وملونة وجذابة
- ✅ تحويل التقارير إلى PDF احترافية
- ✅ إرسال التقارير مباشرة بالبريل الإلكتروني
- ✅ توصيات أمنية متقدمة

---

## 📦 محتويات الحزمة

### الملفات الرئيسية:

1. **WiFi-Guardian-Manager.ps1** 🎮
   - مدير شامل وواجهة تفاعلية
   - يجمع جميع الأدوات في مكان واحد
   - سهل الاستخدام للمبتدئين والمحترفين

2. **router_security_audit.ps1** 🔍
   - فحص أمني متقدم للشبكة
   - كشف الأجهزة والمعلومات التفصيلية
   - اكتشاف شبكات WiFi القريبة
   - توصيات أمنية

3. **generate_security_report.ps1** 📊
   - إنشاء تقرير HTML منسق وملون
   - جدول بمعلومات الأجهزة
   - درجة تقييم الأمان
   - توصيات تفصيلية

4. **pdf_email_sender.ps1** 📧
   - تحويل HTML إلى PDF احترافي
   - إرسال التقرير بالبريل الإلكتروني
   - دعم Gmail و الخوادم الأخرى

## 📖 شرح الخيارات

### الخيار 1: فحص أمان الشبكة الكامل
يقوم بـ:
- اكتشاف عنوان IP الراوتر
- قائمة واجهات الشبكة
- اكتشاف جميع الأجهزة المتصلة
- معلومات نظام التشغيل والموديل
- معلومات شبكات WiFi القريبة
- توصيات أمنية

### الخيار 2: إنشاء تقرير شامل
ينتج:
- تقرير HTML منسق بألوان جميلة
- معلومات النظام والشبكة
- جداول منظمة للأجهزة
- درجة تقييم الأمان
- توصيات مفصلة

### الخيار 3: تحويل إلى PDF
يقوم بـ:
- تحويل HTML إلى PDF احترافي
- استخدام Microsoft Edge أو Chrome
- إنشاء ملف PDF قابل للطباعة

### الخيار 4: إرسال بالبريل
يرسل:
- ملف PDF للتقرير
- رسالة بريد جذابة ومنسقة
- معلومات شاملة للمستقبل

### الخيار 5: تنفيذ كامل
يقوم بـ:
1. الفحص الأمني الكامل
2. إنشاء تقرير HTML
3. تحويل إلى PDF
4. إرسال بالبريل الإلكتروني

## ⚙️ إعدادات البريل الإلكتروني

### لاستخدام وظيفة إرسال البريل مع Gmail:

#### الخطوة 1: تفعيل المصادقة الثنائية
1. انتقل إلى حساب Google الخاص بك
2. اختر "الأمان" (Security)
3. فعّل المصادقة الثنائية

#### الخطوة 2: إنشاء كلمة مرور تطبيق
1. انتقل إلى: https://myaccount.google.com/apppasswords
2. اختر "Mail" و "Windows Computer"
3. انسخ كلمة المرور المولدة

#### الخطوة 3: تحديث السكريبت
```powershell
# افتح pdf_email_sender.ps1
# ابحث عن:
$fromEmail = "your-email@gmail.com"
$fromPassword = "your-app-password"

# وحدّثها بـ:
$fromEmail = "ibra90492@gmail.com"
$fromPassword = "[كلمة المرور من الخطوة 2]"
```

## 📊 معلومات المخرجات

### التقرير يحتوي على:

1. **معلومات النظام**
   - اسم الكمبيوتر
   - اسم المستخدم
   - نظام التشغيل

2. **معلومات الشبكة**
   - عنوان IP الراوتر
   - اسم الشبكة الحالية
   - عدد الأجهزة المتصلة

3. **واجهات الشبكة**
   - قائمة بجميع الواجهات
   - عناوين IP لكل واجهة

4. **الأجهزة المتصلة**
   - عنوان IP لكل جهاز
   - عنوان MAC
   - حالة الاتصال

5. **درجة الأمان**
   - تقييم من 0 إلى 100
   - تصنيف (ممتاز/جيد/ضعيف)

6. **التوصيات**
   - 12 توصية أمنية مفصلة
   - خطوات عملية للتطبيق

## 🔒 نصائح أمنية

### أساسيات الأمان:

1. **تغيير كلمة المرور**
   - استخدم كلمة مرور قوية (16+ حرف)
   - أحرف كبيرة + صغيرة + أرقام + رموز

2. **تحديث البرنامج**
   - حافظ على تحديث برنامج الراوتر
   - تحقق من موقع المصنع دورياً

3. **تعطيل WPS**
   - WPS يحتوي على ثغرات أمنية
   - عطّله من إعدادات الراوتر

4. **استخدام WPA2/WPA3**
   - تجنب WEP القديمة
   - استخدم التشفير الحديث

5. **مراقبة الأجهزة**
   - راقب الأجهزة المتصلة بانتظام
   - ابحث عن أجهزة غير معروفة

6. **MAC Filtering**
   - استخدم تصفية عناوين MAC
   - اسمح فقط بالأجهزة الموثوقة

## 🐛 استكشاف الأخطاء

### مشكلة: السكريبت لا يعمل

**الحل:**
```powershell
# تحقق من ExecutionPolicy
Get-ExecutionPolicy

# غيّرها إلى Bypass (مؤقتاً)
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
```

### مشكلة: لا يتم إرسال البريد

**التحقق:**
1. تحقق من اتصالك بالإنترنت
2. تأكد من صحة بيانات Gmail
3. تحقق من كلمة مرور التطبيق
4. تأكد من تفعيل المصادقة الثنائية

### مشكلة: لا يتم العثور على الأجهزة

**الحل:**
1. تأكد من أن الأجهزة متصلة بـ WiFi
2. قد تكون الأجهزة محظورة من الظهور
3. تحقق من إعدادات الراوتر
